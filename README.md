# About
**Easel Does It** is a simple mod that aims to make working with paintings easier, as first conceptualised [here](https://x.com/GlyphyArt/status/1787250884621054302).

Modrinth: https://modrinth.com/mod/easel-does-it/
Curseforge: https://www.curseforge.com/minecraft/mc-mods/easel-does-it

⚠️ **Warning**: **Easel Does It** requires [Blueprint](https://modrinth.com/mod/blueprint) for all versions.

⚠️ **Fast Painting players**: Please go to the Fast Paintings config and set the `nbt_drop` value to `WHEN_PLACED_WITH_NBT` for intended behavior with this mod.
